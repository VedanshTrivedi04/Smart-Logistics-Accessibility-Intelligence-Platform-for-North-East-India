# NER Logistics Platform — Backend API

FastAPI application server for the Smart Logistics & Accessibility Intelligence Platform for North-East India (SIH 2026 — Problem 26002, MDoNER).

- **Framework**: FastAPI (Python 3.12)
- **Database**: PostgreSQL with PostGIS on Neon Serverless (SQLAlchemy + Alembic)
- **Broker & Cache**: Redis
- **Storage**: MinIO S3-compatible private object storage

See `../pre-devlopment-assets/ner-project/` and `../aiml developer.md` for architecture and roadmap documentation.
